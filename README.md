# Polynomial Interpolation: Lagrange, Newton and Hermite

**Module:** Mathematics for AI
**Level:** Master 1
**Author:** Abir Ben Harrou

## Description
This project implements three polynomial interpolation methods
(Lagrange, Newton with divided differences, and Hermite) in Python,
and compares them with the original function as the number of
equidistant interpolation points increases. The goal is to study
Runge's phenomenon.

## Functions studied
- f(x) = 1/(1+x²) on [-5, 5]
- f(x) = sin(x) on [-π, π]

## Requirements
- Python 3
- NumPy
- Matplotlib
